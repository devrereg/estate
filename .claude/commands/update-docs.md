개발 완료 후 변경사항을 CLAUDE.md 프로젝트 문서에 반영한다.

## 절차

1. **변경 파일 확인**: `git diff --stat HEAD` 및 `git status`로 변경된 파일 목록 파악

2. **CLAUDE.md 읽기**: 현재 문서 내용을 읽어서 구조 파악

3. **변경사항 분류**:
   - 새 파일/디렉토리 추가 → "핵심 파일 구조" 섹션 업데이트
   - 새 의존성 추가 → "기술 스택" 섹션 업데이트
   - DB 스키마 변경 → "DB 스키마" 섹션 업데이트
   - 알고리즘 변경 → "예측 알고리즘" 섹션 업데이트
   - 새 API 라우트 → 파일 구조에 추가
   - 새 페이지/컴포넌트 → 파일 구조에 추가
   - 새 코딩 패턴 → "코딩 규칙" 섹션에 추가
   - 환경 설정 변경 → "환경 설정" 섹션 업데이트

4. **CLAUDE.md 업데이트**: 해당 섹션만 정확히 수정 (기존 내용 유지, 변경분만 추가/수정)

5. **변경 요약 출력**: 어떤 섹션을 왜 수정했는지 한국어로 간단히 설명

## 규칙
- CLAUDE.md의 전체 구조와 포맷을 유지할 것
- 불필요한 내용 추가 금지 (코드에서 파악 가능한 것은 제외)
- 삭제된 기능은 문서에서도 제거
- 새로 추가된 패턴이나 규칙이 있으면 "코딩 규칙" 섹션에 반영
