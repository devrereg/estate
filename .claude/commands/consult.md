한국 수도권 부동산 투자 상담 진입점. real-estate-expert 에이전트를 호출해 사용자의 투자 의사결정 질문에 답하고, 상담 도중 발견된 플랫폼 기능 아이디어를 정리한다.

## 절차

1. **real-estate-expert 호출**: 사용자가 `/consult` 뒤에 적은 질문(`$ARGUMENTS`)을 그대로 전달
2. **상담 결과 수신**: `## 상담 요약` + (있다면) `## 💡 기능 후보` 형식으로 사용자에게 제시
3. **기능 후보 처리**:
   - `## 💡 기능 후보`가 있으면 사용자에게 "이 중 PRD로 정리할 후보가 있나요?" 묻기
   - 사용자가 YES → planner 에이전트 호출 (또는 `/prd <피쳐명>` 안내)
   - 사용자가 NO → 상담만 종료

## 사용 예시

```
/consult 강동구에 5억 투자하려는데 어디가 좋을까?
/consult 송파구 전세가율이 너무 높은데 매수 타이밍이 맞을까?
/consult 잠실 대장이 오르면 어디가 따라 오를까?
```

## 출력 형식

real-estate-expert의 출력을 그대로 전달한 뒤, 기능 후보가 있는 경우 다음 한 줄을 추가:

> 💡 위 기능 후보를 PRD로 정리하려면 `/prd <피쳐명>` 또는 "planner 호출해줘"로 진행하세요.

## 주의 사항

- real-estate-expert는 코드를 수정하지 않음 (read-only 도메인 에이전트)
- 상담 결과 끝에 면책 문구가 포함되어야 함: "본 상담은 참고용입니다"
- 사용자가 기술적 구현 질문 (예: "이 함수 어떻게 짜?")을 하면 real-estate-expert가 아닌 developer로 분기
