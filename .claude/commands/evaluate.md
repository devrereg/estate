구현된 코드의 품질과 완성도를 체계적으로 평가한다.

## 평가 항목 (100점 만점)

### 1. 기능 완성도 (30점)
- AGENTS.md에 명시된 기능이 모두 동작하는가?
- API 라우트가 정상 응답하는가? (`curl`로 실제 호출 테스트)
- 프론트엔드 페이지가 에러 없이 렌더링되는가?
- DB 연결 및 쿼리가 정상 동작하는가?

### 2. 코드 품질 (20점)
- AGENTS.md의 "코딩 규칙"을 준수하는가?
- 중복 코드가 있는가? (유틸 함수로 추출 가능한 로직이 반복되는지)
- 에러 핸들링이 적절한가?
- 불필요한 console.log나 디버그 코드가 남아있는가?

### 3. 데이터 무결성 (15점)
- Prisma 스키마에 적절한 인덱스가 있는가?
- 데이터 수집 시 중복 방지 로직이 있는가?
- NULL 처리가 안전한가?

### 4. UI/UX (15점)
- 로딩 상태가 표시되는가?
- 에러 상태가 사용자에게 보이는가?
- 빈 데이터 상태 처리가 되어있는가?
- 다크 테마 일관성이 유지되는가?

### 5. 성능 (10점)
- API 호출이 배치 처리되는가?
- DB 캐시가 동작하는가? (중복 API 호출 방지)
- 불필요한 리렌더링이 없는가?

### 6. 문서화 (10점)
- AGENTS.md가 현재 코드 상태를 정확히 반영하는가?
- DB 테이블/컬럼에 설명이 있는가?
- 새 개발자가 README만 보고 프로젝트를 이해할 수 있는가?

## 평가 절차

1. **AGENTS.md 읽기**: 프로젝트 명세 파악
2. **자동 테스트 실행**:
   ```
   # 빌드 테스트
   npm run build 2>&1 | tail -5
   
   # API 상태 확인
   curl -s http://localhost:3000/api/predict/status
   
   # 페이지 렌더링 확인
   curl -s http://localhost:3000 -o /dev/null -w "%{http_code}"
   curl -s http://localhost:3000/trends -o /dev/null -w "%{http_code}"
   curl -s http://localhost:3000/predict -o /dev/null -w "%{http_code}"
   
   # 컴파일 에러 확인
   cat .next/dev/logs/next-development.log | grep -i "error" | tail -10
   ```
3. **코드 리뷰**: 주요 파일 읽고 코딩 규칙 준수 확인
4. **점수 산출**: 각 항목별 점수 + 감점 사유 + 개선 제안
